Josephus Problem

A Data Structures implementation and interactive demonstration of the Josephus Problem.

Problem

There are N people standing in a circle. Starting from the first person, every M-th person is eliminated until only one person remains.

The task is to determine which person survives.

Interactive Solver

Result

Survivor: —

Elimination Order

  1. Enter N and M, then press Solve.

C++ Implementation

The following is the C++ implementation of the Josephus Problem. It can be compiled and executed using OnlineGDB.

Example

Consider:

  • N = 10
  • M = 3

The people are numbered from 1 to 10. Every third person is eliminated. The process continues until only one person remains.

The surviving person is 4.

Concepts Used
